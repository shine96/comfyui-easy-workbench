# ComfUI Workbench

把 ComfyUI 变成**简易工作台**：顶部看资源占用，左侧只放提示词和参数，中间保留原生节点画布，右侧直接看生成的图片 / 视频。

```
┌──────────────────────────────────────────────────────────────────────┐
│ ComfyUI 原生顶栏（可一键隐藏）                                        │
├──────────────────────────────────────────────────────────────────────┤
│ 工作台 │ 当前工作流 │ CPU 38% │ 内存 21.4/32 GB │ 显卡 68% │ 显存 …   │ ← 资源占用
├───────────────┬──────────────────────────────┬───────────────────────┤
│ 提示词与参数   │                              │ 输出结果              │
│ · 正面提示词   │      ComfyUI 原生节点画布     │ ┌────┐┌────┐         │
│ · 负面提示词   │      （完全保留原有操作）     │ │图片││图片│         │
│ · 步数 / CFG   │                              │ └────┘└────┘         │
│ · 尺寸 / 种子  │                              │ ┌────┐               │
│               │                              │ │视频│               │
├───────────────┤                              │ └────┘               │
│  ▶ 运行        │                              │                       │
└───────────────┴──────────────────────────────┴───────────────────────┘
```

## 功能

**顶部资源占用条**
- CPU 占用率、内存用量、显卡利用率、显存用量、队列状态，按 1.5 秒轮询（可调）
- 支持 CUDA / Apple MPS / XPU；没有 torch 时自动退化为 `nvidia-smi`
- 没有 psutil 时退化为 `os.getloadavg` / `vm_stat`，不会因为缺依赖而报错
- 后端接口不可用时自动退化为 ComfyUI 自带的 `/system_stats`
- 右侧有「原生界面」按钮，一键回到原生界面（进得去也出得来）

**左侧 提示词与参数**
- 自动扫描当前画布，把参数按节点分组显示：文本类是多行输入框，数值 / 下拉 / 开关是对应控件
- 通过连线自动识别**正面 / 负面提示词**（读取 `positive` / `negative` 输入），并打上彩色标签
- 双向同步：面板改 → 写回节点；节点上改 → 面板自动跟随（正在输入的控件不会被抢）
- 种子参数带「随机」按钮；每组可折叠；可给参数点星标，再用「常用」筛选只看关键项
- 顶部内置工作流下拉框：列出 `user/default/workflows` 下的工作流，可一键载入 / 另存为

**中间 节点画布（极简模式）**
- 仍然是 ComfyUI 原生画布，节点拖拽 / 连线 / 右键菜单 / 快捷键都不受影响
- **只显示流程节点**：自动收起画布上的原生外壳 —— 右下角画布菜单、左下角 FPS 信息（T/F/N/V）、选中时浮出的工具条、小地图
- **连线简单易懂**：连线改成直线、去掉中点标记，一眼看清数据流向
- **执行动效**：正在执行的节点会呼吸发光，数据沿着它的连线流动；执行结束自动停下，不空转
- 收起的是 ComfyUI 自己的设置项，所以**退出工作台会原样还原**你原来的偏好；顶栏的 ▦ 按钮可随时切换
- 插件不改动 ComfyUI 的 DOM，只给画布容器加一个类名，用 CSS 把它定位到中间区域，避免和前端框架打架
- 左右栏宽度可拖动，双击分隔条复位，宽度记忆在本地

**右侧 输出结果**
- 实时接收 `executed` 事件，本次生成的图片 / 视频 / 音频 / 文本立刻出现
- 启动时扫描输出目录，历史产物一并列出（按修改时间倒序）
- 点击放大预览：图片支持滚轮缩放、拖拽平移、`←` `→` 切换、`Esc` 关闭
- 每个卡片可下载、可在系统文件管理器中定位
- **右键卡片 → 删除该文件**：从服务器磁盘上彻底删除（不可恢复），删除前会弹确认框；大图预览右上角也有删除按钮

**左下角 运行按钮**
- 把当前工作流加入执行队列，执行时按钮有呼吸效果，右侧显示进度和当前节点
- 旁边的「停止」按钮中断执行；`Ctrl + Enter` 快捷运行

**一键诊断（`Ctrl + Shift + D`）**
- 顶部资源条右侧的 🐞 按钮，或快捷键，随时生成一份可复制的报告
- 报告包含：画布容器有没有被接管、命中了哪些隐藏规则、参数提取到多少节点/参数、后端接口是否可用、原生弹层有没有被工作台遮住
- 出问题时把报告贴进 issue 即可定位，不用自己翻控制台

## 安装

把整个目录放进 ComfyUI 的 `custom_nodes` 里即可：

```bash
# 方式一：软链（推荐，改代码后重启 ComfyUI 就生效）
./install.sh /path/to/ComfyUI

# 方式二：直接复制
cp -r . /path/to/ComfyUI/custom_nodes/comfui-workbench
```

然后**重启 ComfyUI**，刷新浏览器页面。

可选依赖（装了资源读数更准，不装也能用）：

```bash
# 用 ComfyUI 自己的 python 环境
/path/to/ComfyUI/venv/bin/pip install psutil
```

也可以在 ComfyUI Manager 里「Install from Git URL」安装本仓库。

## 使用

| 操作 | 说明 |
| --- | --- |
| `Ctrl + Shift + B` | 切换简易工作台 / 原生界面 |
| `Ctrl + Enter` | 运行当前工作流（沿用 ComfyUI 原生快捷键，插件不重复注册） |
| `Ctrl + .` | 中断当前执行 |
| `Ctrl + Shift + D` | 生成界面诊断报告（可一键复制） |
| 点顶栏「原生界面」 | 回到 ComfyUI 原生界面（侧栏 / 设置 / 插件管理 / 重启都会回来） |
| 点顶栏 ▦ | 切换极简画布（只显示流程节点 / 显示画布菜单和工具条） |
| 点顶栏「原生菜单」 | 显示 / 隐藏 ComfyUI 原生顶栏 |
| 拖动分隔条 | 调整左右栏宽度（双击复位） |
| 点参数左边星星 | 标记常用，配合「常用」按钮筛选 |

> **怎么退出简易工作台？** 点顶栏那个强调色的「原生界面」按钮，一步就回到原生界面。
> 之所以必须留一个看得见的按钮：`Ctrl/Cmd + Shift + B` 是 Chrome 自己的快捷键（切换书签栏），
> 浏览器会直接吃掉它，页面收不到事件 —— 只靠快捷键的话，在浏览器里可能出不来。
>
> `Ctrl + Enter` 是 ComfyUI 内置命令 `Comfy.QueuePrompt` 的快捷键。ComfyUI 把扩展注册的快捷键当作「默认快捷键」，
> 撞车会直接抛 `Keybinding on Ctrl + Enter already exists on Comfy.QueuePrompt` 并弹红色错误提示，
> 所以本插件**不注册**它，只监听执行事件来刷新界面。

关闭简化模式（或按 `Ctrl + Shift + B`）会**完整还原**原生界面：隐藏的原生侧栏会回来，画布恢复全屏。

### 设置项

在 ComfyUI 的「设置」里搜索 `ComfUI`：

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 启用简易工作台 | 开 | 等同于 `Ctrl + Shift + B` |
| 资源占用刷新间隔 | 1500 ms | 500–10000 |
| 工作台主题 | auto | 跟随 ComfyUI / 强制深色 / 强制浅色 |
| 自动隐藏疑似原生侧栏 / 面板 | 开 | 用属性选择器兜底隐藏，跨版本更稳；误伤时关闭 |
| 额外隐藏的原生元素选择器 | 空 | 逗号分隔的 CSS 选择器；写错的会被自动忽略并打印警告 |
| 画布容器选择器 | 空 | 留空自动检测；画布没被挤到中间时，填上画布容器的选择器（诊断报告里能看到） |
| 极简画布（只显示流程节点） | 开 | 收起画布菜单 / FPS / 浮动工具条 / 小地图，连线改直线并去掉中点标记；退出工作台原样还原 |
| 连线动效 | 开 | 执行中节点呼吸发光、数据沿连线流动；系统开启「减少动态效果」时自动关闭 |

## 后端接口

插件自带的只读接口（都在 `/comfui-workbench/` 下，所有路径都做了越权校验）：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/stats` | 资源占用快照（0.5 秒缓存） |
| GET | `/outputs?limit=120` | 输出目录里的图片 / 视频 / 音频 |
| GET | `/workflows` | 用户工作流列表 |
| GET | `/workflow?name=…` | 读取工作流 JSON |
| POST | `/workflow` | 保存工作流 JSON（自动备份同名旧文件） |
| POST | `/reveal` | 在系统文件管理器中定位文件 |
| POST | `/delete` | 从磁盘删除输出目录里的一个产物 |
| GET | `/ping` | 连通性检查 |

删除接口的约束（任意一条不满足都拒绝）：

- 只允许删**输出目录**里的文件，`type` 必须是 `output`（不能删 `input` / `temp`）
- 文件名必须是纯文件名，不能带路径分隔符，子目录只能通过 `subfolder` 传
- 解析后的路径必须落在输出目录内，并额外用 `realpath` 校验一次，防止软链逃逸
- 扩展名必须在图片 / 视频 / 音频 / `.txt` 白名单内（不会误删模型、配置等文件）

## 预览页（不需要 ComfyUI）

`preview/index.html` 用 mock 的 ComfyUI（`app` / `api`）驱动**同一份**插件代码，
用来在没有 ComfyUI 的环境里检查布局、参数提取、运行流程：

```bash
python3 -m http.server 8123
# 浏览器打开 http://127.0.0.1:8123/preview/index.html
```

预览页里点「运行」会模拟一次执行，右侧会出现新图片。

## 自检

仓库自带两个自检脚本，改代码后可以直接跑（都逐项打印 ✅/❌，失败时以非 0 退出码结束，可直接接 CI）：

```bash
# 后端：假 folder_paths / server，验证采集、文件、接口
python3 tools/backend-check.py

# 前端：无头 Chrome + CDP，验证真实布局像素、参数提取、输出画廊
node tools/preview-check.mjs --deep
node tools/preview-check.mjs --run     # 额外验证运行按钮 → 输出画廊
node tools/preview-check.mjs --deep --run   # 全部（125 项断言）
node tools/preview-check.mjs --json    # 额外打印原始报告，排查用
```

前端自检覆盖：三栏像素位置与互不重叠、原生侧栏隐藏 / 顶栏不误伤、五个资源指标、
参数分组与正负面提示词识别、画布↔面板双向同步、主题切换、模式开关的完整还原、
分隔条拖动、**画布选择器自定义与写错回退**、**隐藏选择器容错**、
**弹层不被隐藏规则误伤且盖过工作台**、**确认框/诊断面板不被自己的遮罩盖住**、
**快捷键不与 ComfyUI 原生撞车**、**「原生界面」逃生按钮真的能退出**、
**启动布局自检（正常静默 / 异常报错）**、
**右键删除（取消不删 / 确认后消失且重新扫描不回来）**、
**大图预览自适应屏幕与缩放夹紧**、**极简画布收起与还原**、**连线动效几何与启停**、
**一键诊断报告字段**。

## 兼容性与排错

出问题时先按 `Ctrl + Shift + D`（或点顶栏 🐞 按钮）生成诊断报告，它会把下面这些信息一次列全：
画布有没有被接管、命中了哪些隐藏规则、参数提取到多少、后端接口是否可用。

- **界面看起来没变化**：确认浏览器刷新过，控制台是否打印 `[ComfUI Workbench] 已注册`。
- **点原生「设置」没反应 / 弹窗空白**：简化模式的隐藏规则以前会连弹层内部的元素一起隐藏（ComfyUI 设置对话框里的分类导航 class 就带 `sidebar`）。现在隐藏规则已豁免对话框 / 下拉菜单 / 右键菜单，并把它们抬到工作台之上；如果仍不正常，按 `Ctrl + Shift + D` 看报告里「原生弹层」一节。
- **想用原生侧栏 / 插件管理 / 重启，但界面上找不到**：点顶栏强调色的「原生界面」按钮即可完整回到原生界面。简化模式会隐藏原生侧栏，而 ComfyUI Manager 之类的插件常常就挂在侧栏上。
- **一进页面就提示布局自检有问题**：插件启动 2.5 秒后会检查「画布有没有接管、资源条有没有压住原生顶栏」，发现问题会在控制台和提示条里说明原因，按 `Ctrl + Shift + D` 有完整报告。
- **原生侧栏没被隐藏**：说明前端类名变了，在设置里给「额外隐藏的原生元素选择器」补上选择器（例如 `.your-sidebar`）；诊断报告里「隐藏规则」一节会列出当前命中的选择器。
- **资源条全是 `—`**：后端接口没注册成功（看 ComfyUI 启动日志），此时会自动退化为 `/system_stats`，CPU 和显卡利用率本身就没有这项数据。
- **画布没被挤到中间**：自动检测没命中，在设置里给「画布容器选择器」填上画布容器的 CSS 选择器（诊断报告里「画布容器」一节会显示当前结果）。
- **某个选择器写错了**：无效项会被自动忽略并在控制台打警告，不会连累其它规则。
- 插件**不会修改你的工作流文件**（另存为时会先备份同名旧文件）。唯一会动磁盘的操作是「右键删除产物」和「另存为工作流」，两者都有确认框与路径校验。
